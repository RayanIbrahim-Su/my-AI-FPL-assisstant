# مساعد Fantasy Premier League الذكي

مشروع بايثون بسيط يجلب بيانات لاعبي FPL الحية، ويستخدم GPT-4 لتحليلها
وتقديم توصيات التشكيلة والتبديلات، عبر واجهة Streamlit.

## هيكل المشروع

```
fpl_assistant/
├── fpl_data.py       # جلب ومعالجة بيانات FPL من الـ API الرسمي
├── ai_advisor.py      # الربط مع GPT-4 وبناء System Prompt
├── app.py             # واجهة Streamlit
├── requirements.txt
└── README.md
```

## التشغيل

1. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```

2. تشغيل التطبيق:
   ```bash
   streamlit run app.py
   ```

3. أدخل مفتاح OpenAI API الخاص بك في الشريط الجانبي (لا يُخزَّن، يُستخدم فقط أثناء الجلسة).

## ملاحظات مهمة

- **بيانات الإصابات**: FPL API الرسمي يوفّر حقلي `chance_of_playing_next_round` و `news`
  ضمن بيانات كل لاعب — لا حاجة لكشط مصادر خارجية غير موثوقة لهذا الغرض.
- **التكلفة**: يتم إرسال فقط أفضل 40 لاعبًا مرشحًا (حسب الفلترة) للنموذج، وليس كل
  قاعدة اللاعبين (~600+)، لتقليل تكلفة الاستدعاء وتحسين دقة الإجابة.
- **التخزين المؤقت**: بيانات FPL تُحدَّث كل ساعة تلقائيًا (`@st.cache_data(ttl=3600)`)
  لتقليل عدد الطلبات على الـ API الرسمي.
- **استبدال النموذج**: لو تفضّل استخدام Claude بدل GPT-4، غيّر فقط محتوى `ai_advisor.py`
  لاستخدام `anthropic` بدل `openai` — بقية المشروع (جلب البيانات والواجهة) يبقى كما هو.

## أفكار للتوسّع لاحقًا

- إضافة تحليل صعوبة المباريات القادمة (fixtures) لكل نادي ضمن التوصية.
- حفظ سجل الأسئلة والتوصيات في قاعدة بيانات SQLite.
- إضافة رسم بياني (matplotlib/plotly) لمقارنة الفورم بين عدة لاعبين.
- دعم "Wildcard" و"Free Hit" كأوضاع تحليل خاصة بقواعد مختلفة.
